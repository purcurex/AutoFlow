# Shopify 店铺搜索

通过图片或关键词搜索 Shopify 店铺，快速找到销售特定产品的店铺。

## 功能入口

点击顶部导航栏的 **Shopify** 按钮

## 搜索方式

### 1. 图片搜索

通过产品图片URL搜索销售该产品的 Shopify 店铺。

**使用场景：**
- 看到某产品图片，想找到销售该产品的店铺
- 分析竞争对手产品来源

**操作步骤：**
1. 选择「图片搜索」标签
2. 输入产品图片的 URL 地址
3. 点击「搜索」按钮
4. 查看搜索结果列表

**搜索原理：**
- 使用 Google Lens 反向图片搜索识别产品
- 从搜索结果中提取关键词
- 使用 `allinurl:/collections/all` 指令精准匹配 Shopify 店铺

### 2. 关键词搜索

通过产品关键词搜索相关 Shopify 店铺。

**使用场景：**
- 研究某个品类的 Shopify 店铺
- 寻找竞品店铺

**操作步骤：**
1. 选择「关键词搜索」标签
2. 输入产品关键词（如：时尚连衣裙、宠物用品）
3. 点击「搜索」按钮
4. 查看搜索结果列表

**搜索原理：**
- 搜索查询：`"关键词" allinurl:/collections/all`
- `allinurl:/collections/all` 匹配 Shopify 店铺的产品目录页
- 支持独立域名和 myshopify.com 域名

## 搜索结果

每个搜索结果包含：

| 字段 | 说明 |
|------|------|
| 店铺名称 | Shopify 店铺名称 |
| 店铺地址 | 店铺 URL（点击可直接访问） |
| 描述 | 店铺简介或产品描述 |
| 流量数据 | 月访问量、排名等信息 |

## 保存结果

点击「保存到笔记」按钮，将搜索结果保存为新笔记。

**笔记格式：**
```html
<h2>Shopify店铺搜索结果</h2>
<p>搜索产品：关键词</p>
<p>共找到 N 个相关店铺：</p>
<p><strong>1. 店铺名称</strong></p>
<p>店铺地址：<a href="url">域名</a></p>
<p>流量数据：月访问 50K | 排名 #150K</p>
...
```

## 导出 Excel

Shopify 搜索结果笔记导出为 Excel 时，会自动解析为结构化表格：

| 字段 | 说明 |
|------|------|
| 笔记名称 | 保存时的笔记标题 |
| 店铺名称 | 店铺名称 |
| 店铺URL | 店铺完整链接 |
| 流量数据 | 月访问量、排名等 |
| 搜索时间 | 执行搜索的时间 |

**导出特点：**
- 每个店铺占一行
- 多篇搜索笔记可合并导出
- 自动识别 Shopify 搜索结果笔记

## 搜索限制

- 每日搜索次数：250 次
- 单次返回结果：最多 20 个店铺

## 技术实现

### API 端点

| 方法 | 端点 | 说明 |
|------|------|------|
| POST | `/api/shopify-search/by-image-url` | 图片URL搜索 |
| POST | `/api/shopify-search/by-keyword` | 关键词搜索 |
| POST | `/api/shopify-search/by-image-upload` | 图片上传搜索 |

### 外部服务

| 服务 | 用途 |
|------|------|
| SerpAPI | Google 搜索、Google Lens 图片搜索 |
| Host.io | 域名流量数据 |

### 环境配置

```env
# SerpAPI配置（必需）
SERPAPI_KEY=your-serpapi-key

# Host.io配置（可选，用于流量数据）
HOSTIO_API_KEY=your-hostio-key
```

## 最佳实践

1. **精准关键词**：使用具体的产品名称而非宽泛品类
2. **图片URL**：确保图片URL可公开访问
3. **结果筛选**：关注流量数据，优先查看高流量店铺
4. **保存习惯**：及时保存搜索结果，方便后续分析
