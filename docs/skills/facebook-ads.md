# Facebook Ads 搜索

通过关键词搜索 Facebook 广告，分析竞品广告策略和素材。

## 功能入口

点击顶部导航栏的 **Facebook Ads** 按钮

## 搜索方式

### 关键词搜索

通过产品或品牌关键词搜索正在投放的 Facebook 广告。

**使用场景：**
- 分析竞品广告策略
- 获取广告创意灵感
- 研究行业广告趋势

**操作步骤：**
1. 输入搜索关键词（产品名、品牌名等）
2. 点击「搜索」按钮
3. 查看搜索结果列表

**搜索原理：**
- 使用 SerpAPI 搜索 Facebook 广告库
- 结合 Shopify 店铺搜索，找到广告背后的店铺
- 过滤并返回相关广告结果

## 搜索结果

每个搜索结果包含：

| 字段 | 说明 |
|------|------|
| 广告名称 | 广告标题或品牌名 |
| 链接地址 | 广告落地页 URL |
| 描述 | 广告文案摘要 |

## 保存结果

点击「保存到笔记」按钮，将搜索结果保存为新笔记。

**笔记格式：**
```html
<h2>Facebook Ads 搜索结果</h2>
<p>搜索关键词：关键词</p>
<p>共找到 N 条广告：</p>
<p><strong>1. 广告名称</strong></p>
<p>落地页：<a href="url">域名</a></p>
...
```

## 搜索限制

- 每日搜索次数：250 次
- 单次返回结果：最多 20 条广告

## 技术实现

### API 端点

| 方法 | 端点 | 说明 |
|------|------|------|
| POST | `/api/facebook-ads/by-image-url` | 图片URL搜索 |
| POST | `/api/facebook-ads/by-keyword` | 关键词搜索 |
| POST | `/api/facebook-ads/stats` | 获取搜索统计 |

### 外部服务

| 服务 | 用途 |
|------|------|
| SerpAPI | Facebook 广告库搜索 |
| Host.io | 域名流量数据 |

### 环境配置

```env
# SerpAPI配置（必需）
SERPAPI_KEY=your-serpapi-key

# Host.io配置（可选）
HOSTIO_API_KEY=your-hostio-key
```

## 与 Shopify 搜索联动

Facebook Ads 搜索与 Shopify 搜索配合使用效果更佳：

1. **先搜索广告** → 了解竞品广告策略
2. **再搜索店铺** → 深入分析店铺运营
3. **保存笔记** → 建立竞品分析资料库

## 最佳实践

1. **关键词选择**：
   - 使用具体产品名而非泛词
   - 尝试品牌名 + 产品名组合
   - 关注行业热门词汇

2. **广告分析维度**：
   - 广告文案风格
   - 落地页设计
   - 产品定价策略

3. **竞品跟踪**：
   - 定期搜索竞品关键词
   - 记录广告变化趋势
   - 分析投放策略调整

## 常见问题

### Q: 搜索结果为空？
- 尝试更换关键词
- 检查关键词拼写
- 使用更通用的产品类目

### Q: 结果不够精准？
- 使用引号包裹精确词组
- 添加品牌限定词
- 结合多个关键词搜索

### Q: 如何判断广告质量？
- 查看落地页设计质量
- 关注店铺流量数据
- 分析产品评价情况
