System Operation Manual

AutoFlow 系统操作手册

面向 Dropshipping 海外小 B 客户开发场景，覆盖搜品、广告发现、店铺识别、客户筛选、AI 话术、半自动建联、报价准备及 FOP 移交。

适用角色：外贸销售员 / 销售主管 / 系统管理员界面：简体中文 / English主题：白色 / 黑色

01手册概览

本手册先解释 AutoFlow 的系统结构、责任边界和完整业务流程，再按页面给出操作步骤。建议首次使用者顺序阅读，熟悉后可通过左侧目录直接跳转。

核心目标

帮助业务员更快发现适合 Dropshipping 合作的海外店铺并建立有效联系。

一期重点

搜品、搜店铺、联系方式筛查、线索评分、AI 话术和人工审核建联。

二期预留

金蝶云苍穹 FOP 产品成本、物流运费、正式线索和商机接口。

当前能力状态

能力状态使用说明
登录、注册、权限控制可用普通用户和管理员权限分离。
关键词 / 图片搜客工作流已实现执行依赖 PipiAds API Key 与可用额度。
Shopify 识别、清洗和线索评分已实现评分用于辅助排序，联系人仍需人工核验。
智谱 GLM 开发话术已实现依赖模型额度；所有话术必须人工审核。
WhatsApp / Email 建联半自动系统打开渠道，业务员确认并真实发送。
报价草稿与版本可用可以录入阶梯价、目的国和包裹条件。
FOP 实时成本、运费和正式 CRM二期预留页面入口存在，但真实金蝶适配器尚未接入。
重要验收边界页面出现 FOP 按钮或报价矩阵，不表示已经取得真实产品成本或物流运费。正式报价必须以 FOP 接口返回及审批结果为准。

02产品定位与角色边界

AutoFlow 负责

  • 产品关键词、图片和店铺发现工作流
  • 广告证据、Shopify 检测和联系方式清洗
  • 可解释线索评分和业务员快速筛选
  • 智谱 GLM 话术草稿及人工审核
  • 半自动外部建联和本地下一步行动
  • 产品阶梯价与目的国报价条件准备

FOP 负责

  • 正式线索、客户、商机和商机阶段
  • 权威跟进记录和销售责任归属
  • 商品资料、采购成本与价格政策
  • 物流渠道和运费试算模型
  • 订单、履约、物流、售后、财务和结算
  • 正式报价相关审批与业务规则

角色职责

角色主要操作关键责任
外贸销售员创建工作流、筛选线索、核验联系人、审核话术、发送建联、准备报价保证联系对象、话术和状态回填真实准确。
销售主管查看线索质量、建联进度、报价完整性和 FOP 移交状态监督业务质量与异常处理。
系统管理员账号权限、配置检查、兼容业务记录管理和运行排障保护密钥、数据和管理员权限。

05使用前准备

5.1 访问与运行条件

  • 推荐最新版 Microsoft Edge 或 Google Chrome。
  • 本地前端：http://127.0.0.1:5173。
  • 本地后端：http://127.0.0.1:3000。
  • 使用前确认前端、后端和 PostgreSQL 数据库均正常运行。
  • 账号由管理员安全分配，不在公共文档保存密码。

5.2 外部服务

服务用途使用前检查
PipiAds / PipiSpy广告及时性数据和落地页证据API Key 有效且 credits 充足。
智谱 BigModelGLM-5.2 生成客户开发话术API Key、模型权限、余额或资源包有效。
目标站点 / Shopify 店铺店铺识别、联系人证据核验当前网络可正常访问目标页面。
金蝶云苍穹 FOP正式 CRM、成本和运费当前为二期预留，不能按已联通验收。
密钥管理所有 API Key 只允许配置在后端本地环境或正式密钥服务中，业务员不需要在浏览器填写。

06登录与全局界面

6.1 登录

  1. 打开 AutoFlow，确认页面显示 HyperZone Logo 和 AutoFlow 品牌。
  2. 在“邮箱”输入管理员分配的登录邮箱。
  3. 在“密码”输入密码，单击“登录”。
  4. 登录成功后进入“工作台”；失败时核对邮箱、密码、后端和数据库状态。

6.2 工作台与导航

左侧菜单依次为工作台、搜客工作流、客户线索、客户建联、客户报价、跟进与移交；个人设置和系统管理位于底部。顶部提供新建工作流、语言、主题和用户菜单。

6.3 语言、主题与移动端

  1. 单击顶部“简体中文 / English”选择器，界面立即切换语言。
  2. 单击月亮或太阳图标，在白色与黑色主题之间切换。
  3. 选择结果保存在当前浏览器，下次访问自动恢复。
  4. 移动端单击左上角导航按钮打开菜单，单击灰色遮罩关闭。
截图主题说明为确保屏幕阅读和打印清晰度，本手册全部操作截图统一使用浅色主题。系统仍支持深色主题，可通过顶部主题按钮随时切换。

07创建与执行搜客工作流

7.1 新建工作流

  1. 进入“搜客工作流”，在工作流面板中单击“新建工作流”。
  2. 填写工作流名称，建议采用“市场 + 品类 + 日期”。
  3. 选择“产品关键词”或“产品图片”。图片模式必须填写无需登录即可访问的公开图片 URL。
  4. 填写英文关键词或图片地址，并从国家卡片中选择一个主要目标市场。
  5. 单击“创建工作流”。此时仅创建任务定义，尚未调用外部数据源。

7.2 字段填写建议

字段要求示例
工作流名称选填但建议填写，便于后续识别US Pet Hair Remover 2026-07
起始类型产品关键词或产品图片二选一产品关键词
关键词或图片地址必填；关键词尽量具体，图片 URL 必须公开pet hair remover
目标市场必填；按优先级选择 US、EU、CA、AU 或 OT。OT 表示不限地区搜索US · 美国

7.3 启动与重试

  1. 进入“搜客工作流”，找到状态为“草稿”的任务。
  2. 核对名称、起始线索和目标市场，单击“开始发现”。
  3. 执行中不要重复点击，等待状态由“执行中”变为“已完成”。
  4. 完成后进入“客户线索”查看结果。
  5. 失败时先排查额度、网络、关键词或图片 URL，再单击“重新执行”。
已验证的外部错误PipiAds 返回 442 表示 credits 不足；智谱返回 1113 表示余额或资源包不足。系统会明确失败，不会用模拟数据伪装成功。

08线索筛选与联系人核验

8.1 在线索池快速筛选

  1. 进入“客户线索”。
  2. 按品牌、域名、市场或品类搜索。
  3. 使用状态筛选查看新线索、已筛选、已建联、已回复、商机、已成交或已流失线索。
  4. 优先查看综合评分较高且联系人证据完整的线索。
  5. 单击品牌名称进入客户详情。

8.2 详情核验要点

  • 打开店铺链接，确认域名仍可访问且与目标品牌一致。
  • 查看 Shopify 置信度、广告活跃度、流量和联系人子评分。
  • 单击证据来源，确认邮箱、WhatsApp 或社媒账号属于目标店铺。
  • 优先使用“已验证”或高置信度联系方式。
  • 广告代理、平台客服、第三方目录或失效页面不得当作客户联系方式。
评分的正确用法评分用于排序和辅助判断，不替代人工核验。高分线索也可能因为联系方式过期、店铺变化或来源错误而不适合发送。

09AI 话术与半自动客户建联

9.1 生成并审核话术

  1. 在线索详情确认客户画像、推荐切入点和联系方式证据。
  2. 单击“生成话术”，系统调用智谱 GLM-5.2。
  3. 检查客户称呼、产品匹配、语言、价格、库存、物流时效和合作承诺。
  4. 直接编辑生成内容，删除无法验证的事实。
  5. 确认后单击“审核通过，进入建联”，任务状态变为“待发送”。

9.2 外部发送与状态回填

  1. 进入“客户建联”，选择“待发送”。
  2. 再次核对渠道、联系人、主题和消息正文。
  3. 单击“打开 WhatsApp / Email”，在外部页面人工确认并发送。
  4. 真实发送成功后返回 AutoFlow，单击“标记已发送”。
  5. 收到客户回复后单击“标记已回复”；不适合发送的任务选择“跳过”。
禁止误操作“标记已发送”只是状态回填，不会代替外部渠道真实发送。没有在 WhatsApp 或 Email 中确认成功时，不得点击。

10客户报价工作区

10.1 产品阶梯报价

  1. 从左侧“客户报价”进入，或在线索详情单击“准备客户报价”。
  2. 填写 FOP 商品 / SKU 编码，选择单位和币种。
  3. 为每个数量区间填写最小数量、最大数量和客户单价。
  4. 单击“增加阶梯”扩展价格区间，确保相邻阶梯不重叠。
  5. 最后一个阶梯可以不设置最大数量，表示不封顶。

10.2 目的国与包裹条件

  1. 勾选一个或多个目的国。
  2. 填写包裹数、重量、重量单位、长、宽、高和尺寸单位。
  3. 检查综合报价矩阵是否生成每个“数量阶梯 × 目的国”组合。
  4. 完成字段校验后单击“保存草稿”，后续修改会生成新版本。

10.3 阶梯校验规则

规则正确要求
最小数量必须是大于或等于 1 的整数。
最大数量不得小于最小数量；除最后一阶外应填写。
区间关系相邻阶梯不能重叠。
客户单价每个阶梯均应填写大于 0 的金额。
目的国至少选择一个。
包裹数据包裹数、重量和三边尺寸必须大于 0。
报价版本含义“草稿保存成功”只代表报价输入条件已固化，不代表已经取得 FOP 成本或物流运费。不得把“等待 FOP”或空白金额当作客户最终报价。

11跟进状态与 FOP 移交

“跟进与移交”页面汇总 AutoFlow 内部的新线索、已筛选、已建联、已回复、商机、已成交、已流失和无效状态。它用于移交前的快速查看，不是第二套完整 CRM。

移交成功判定

  • 当前一期中 FOP 按钮属于接口位置预留，适配器不可用时不能判定移交成功。
  • 二期上线后，应以 FOP 返回的线索 ID、商机 ID 和同步状态为准。
  • 超时或失败时保留 AutoFlow 草稿和请求条件，通过幂等键重试，不能重复创建正式客户。
  • 移交后以 FOP 商机阶段和跟进记录为业务权威数据。

12个人设置与系统管理

12.1 个人设置

  1. 进入“个人设置”。
  2. 可修改用户名；邮箱当前不可修改。
  3. 单击头像上传 JPG、JPEG、PNG、GIF 或 WebP，文件最大 5 MB。
  4. 在“界面偏好”中切换语言和显示主题。
  5. 数据管理可导出兼容层业务记录 PDF；导入功能仍在开发中。
  6. 公共电脑使用结束后单击“退出当前账号”。

12.2 管理员页面

只有管理员能进入“系统管理”。当前页面管理原系统兼容层业务记录，可按标题或作者搜索、按表头排序、预览安全过滤后的内容及删除记录。

13状态字典

13.1 工作流状态

状态含义下一步
draft已创建，尚未执行核对参数后开始发现。
running正在调用外部能力并处理证据等待完成，不要重复提交。
completed执行完成进入客户线索查看结果。
failed执行失败排查外部额度、网络和输入后重试。
cancelled已取消根据需要重新创建。

13.2 线索与建联状态

对象状态顺序说明
线索new → qualified → contacted → replied → opportunity → won/lostinvalid 表示不应继续跟进。
建联draft → ready → sent → replied也可以进入 skipped 或 failed。
FOP 同步not_started → pending → succeeded异常进入 failed 或 requires_review。

14排障与安全规范

14.1 常见问题

问题排查方法
页面打不开确认前端端口 5173、后端端口 3000、数据库和启动日志。
登录失败使用邮箱登录，检查密码大小写、后端健康状态和账号是否存在。
工作流没有线索检查状态、PipiAds credits、英文关键词、目标市场和图片 URL 可访问性。

14.2 安全规范

  • 不得在前端、截图、日志、聊天或 Git 仓库暴露 API Key。
  • 不共享个人账号，不把管理员账号用于日常销售。
  • 所有联系人必须经过证据核验，建联应符合 B2B 合规要求。
  • AI 内容必须人工审核，不发送虚构价格、库存、时效和案例。
  • 管理员删除数据前必须二次确认。
  • 对外报价必须经过真实成本、运费和内部审批确认。

15验收检查清单

  • 普通用户可以登录，且看不到系统管理菜单。

  • 白色与黑色主题可切换并保持。

  • 线索可以搜索、筛选并查看证据。
  • 智谱额度充足时可以生成并编辑话术。
  • 建联状态可按合法顺序流转。
  • 外部发送必须经过人工确认。
  • 报价页能校验阶梯、目的国和包裹。
