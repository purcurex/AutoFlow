# 自动目录同步与单据关系更新实施计划

　　按用户确认的五项机制执行：目录全部接入原有调度；增量后查询关系API；来源变更登记持久化任务；关系后到重试；旧图失效；周期补偿。页面只查本地库，FOP业务写操作不变。

- [x] 提取目录采集、导入函数供调度复用，每次新建核验目录，完整分页后发布；相同内容跳过，失败独立退避。
- [x] 新增关系任务迁移，记录根订单、请求版本、成功版本、重试时间；来源变化同时记录旧根，新建链路补新根。
- [x] 增量事务提交后限流处理任务，完整响应原子替换，部分及失败保留待补；并发版本变化不能标为完成。
- [x] 查询忽略过期API关系图，优先当前已验证本地链路；周期补偿未完成及历史根，预算内公平推进。
- [x] 回归分页失败、任务重放、改挂、部分响应、旧版本竞争、自动调度；运行本地迁移与只读真实验证；更新唯一需求说明书。

　　没有修改时间契约的目录使用全量读取、内容比较后更新本地，不能称为源端增量；不根据目录缺行删除数据。单据关系API完整返回表示该根当前关系集合，不能代替源端单据存在性证明。
