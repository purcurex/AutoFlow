01 · 全部API通用要求

本清单仅列FOP需提供的查询API及核心返回字段。可复用已有接口；实体编码、字段编码和接口地址由FOP确认，未提供项标记“待提供”。

项目要求
公共返回字段源实体编码、记录ID、编码、名称（有名称的档案提供中文名）、租户／所属组织ID、适用组织、原始状态值及状态名称、有效／停用标识、创建时间、修改时间。独立关系记录同样提供身份、状态和时间。
关联字段返回关联实体类型及ID；业务员同时明确是FOP用户ID还是员工ID。多对多关系返回完整ID集合或独立关系记录。不得只返回名称。
查询条件组织范围、ID或ID集合、修改时间起止、分页参数；支持完整查询及按修改时间增量查询，包括停用记录。
时间规则创建时间取真实建档时间；修改时间取最后业务变更时间。时间带时区或明确固定UTC+8，并说明精度。缺值返回null并注明缺口，不以接口查询时间填充。
增量与分页修改时间区间采用“起始含、结束不含”；按“修改时间＋记录ID”稳定排序。同一时间多条记录可完整翻页，明确下一页或结束标识。
变更覆盖更名、归属转移、启停、解绑、公私有转换及关系增删均更新修改时间。分录或关系变化须更新父档案时间，或提供独立关系增量。
删除返回软删除返回删除标识和删除时间；硬删除提供删除清单或可完整核对的记录ID清单。明确关系返回为完整集合还是增删差量。
响应规范提供字段类型、可空性和状态枚举；ID按字符串返回。区分成功空数据、无权限、失败和限流，说明最大页长与调用限额。

  1. 各API地址／操作名、实体编码、授权组织范围及请求参数。

  5. 最大页长、调用限额、限流错误及重试要求；尚未支持的字段或能力明确标记“待提供”。
