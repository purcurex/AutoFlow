# 统一下拉选择框

`main.ts` 安装 `installSelectDropdowns`，自动覆盖应用内现有及动态新增的单选下拉框。保留原生 select 的值、label、disabled、表单验证、Vue v-model（含 number 修饰符）和 change/input 事件；多选列表不是弹出式下拉框，不适用此处理。

- 选项使用页面菜单，在控件下方 6px 展开，不自动翻转到上方；接近视口底部时先将控件滚入可用区域。
- 菜单宽度至少等于控件，按最长选项自适应，并在视口内对齐。选项单行显示、不省略；超出屏幕的极长文本可横向滚动，选项较多时纵向滚动。
- 弹层挂载到 body，避免被卡片、表格的 overflow 截断；浅／深主题共用样式，无蓝色焦点外框。
- 支持方向键、Home/End、Enter/空格、首字母匹配、Esc 取消、Tab 离开、点击外部关闭；禁用项不可选择。控件被移除、禁用或切换页面时关闭菜单。
- 原有语言、用户及编辑器按钮菜单已采用 top-full 向下布局；本实现针对浏览器原生选择框造成的系统菜单向上展开及宽度不一致问题。

样式：`frontend/src/styles/select-dropdowns.css`。新业务表单继续使用标准 select，无需单独接入或重写绑定逻辑。
