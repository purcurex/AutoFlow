# 五类履约待办队列

Dashboard 按待审核、待履约、待采购、待配货、待出库排序。全部以履约订单为粒度，同队列去重，不同队列允许重叠。Dashboard 仅跳转到相应岗位工作台，保留本人／部门／管理员及 FOP 交集权限。

- 待审核：已支付、待审核。
- 待履约：已支付、已审核，Shopify 发货仍待同步（含部分同步）。
- 待采购：已支付、已审核，供应商仍有未发货商品（含部分发货；无需采购不计入）。
- 待配货：已支付、已审核，库存未齐套，或已齐套但配货待审核。
- 待出库：已支付、已审核、库存已齐套、配货已审核，尚未全部出库。
- 已取消、已退款、未支付排除；未知状态不能猜测为待办。异常队列保留。
