# 管理员开通员工账号实施计划

**需求：** 系统管理员手动新增员工、选择所属部门、开通前端登录账号，创建时或之后绑定已有 FOP 用户。只拥有业务管理员权限不授予管理操作。

**方案：** 复用组织树、账号页及 FOP 绑定接口。组织员工增加唯一可空 accountId；新增员工可同时开通账号，已有员工可单独开通。账号默认为普通员工及本人业务范围，不接收客户端传入管理员权限。账号与员工同事务创建，重复邮箱／用户名／工号／FOP身份回滚；密码只存 bcrypt，不返回。

关联员工的账号读取同一演示目录，由服务端本人范围过滤业务数据；管理接口仍需系统管理员。本地部门与员工 ID 不等同于 FOP ID，真实接入需后台确认映射与授权，不把保存绑定当成联调成功。已有组织及未关联账号保留原兼容行为。

- [x] 数据迁移及 DTO：员工 accountId 唯一外键；新增员工、已有员工开通账号；嵌套字段白名单、对象类型及密码长度校验。
- [x] 服务端：权限复核、原子写入、防重复、目录关联；账号列表显示员工与部门信息；调部门不扩大经理权限。
- [x] 前端：共享新增员工／账号弹窗，部门下拉、岗位选择、初始密码、可选 FOP 绑定；组织与账号页入口及成功状态。
- [x] 验证：真实数据库 E2E（管理权限、登录、部门关联、重复回滚、本人隔离、绑定唯一性）、前端交互测试、lint/build及独立代码复核；245前端＋486后端＋134接口通过。
- [x] 文档：字段级接口契约、FOP 源码证据及剩余映射／权限验证事项；统一HTML生成及校验通过。
