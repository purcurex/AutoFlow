# 深色主题优化实施计划

**目标：** 修复日历标题、汇总列及客户合计行在深色主题下仍为浅色的问题，统一深色层次、图表文字和品牌图标。

**设计选择：** 沿用现有布局与数据语义，采用石墨蓝页面、稍亮的卡片、蓝紫汇总色、柔和的绿／琥珀状态色。建立共享颜色变量，避免各组件单独覆盖造成漂移。用户已授权直接设计并执行。

**约束：** 不变更业务数据、权限、图表结构、列宽、滚轮及拖动行为；浅色主题保持兼容；保留原Logo，不重绘。

- [x] 修复Vue scoped样式中错误的`:global(.dark) .child`写法（编译后丢失子选择器）；统一汇总与合计行变量。
- [x] 优化日历渐变、状态标识、时间轨道，以及Dashboard/分析/工作台标题、表格、次级文本和深色Logo容器。
- [x] EChart按主题统一坐标轴、图例、tooltip和slider外观；切主题保留已拖动的时间窗口及图表回调。
- [x] 运行针对性测试、类型检查与构建；浏览器验证深浅切换、日历、汇总行/列、客户双行合计与Logo，保留截图。

复核重点：主题切换不改变图表数据或区间；sticky合计背景不透字；dark选择器不污染根元素；原数据/权限保持；浅色可恢复。

## 验证结果

- 前端48个测试文件、250项测试通过；主题切换新增验证覆盖图表数据与formatter保持、拖动窗口保留、浅色恢复。
- ESLint、vue-tsc与Vite生产构建通过；6个组件的深色scoped选择器编译校验通过。
- 浏览器验证：日历标题、注册合计行、业务员汇总列、环比正负标识、客户分仓趋势弹窗及双行合计，深浅主题均正常；控制台无error。
- 汇总/合计标签与数值使用同组颜色变量；客户排名数值轴启用标签防重叠。
- 截图保存在`.runtime/local-demo/dark-dashboard-polish.png`、`dark-receipt-summary.png`、`dark-customer-totals.png`。

后续样式维护：Vue scoped样式使用`.dark .child`形式，不使用`:global(.dark) .child`或`.dark :is(...)`（当前编译器会丢失子选择器或把scope误加到根.dark）；汇总/合计使用共享CSS变量。
