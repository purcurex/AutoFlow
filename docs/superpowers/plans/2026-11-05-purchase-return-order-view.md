# 采购退货履约单视角 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans; final read-only review with superpowers:requesting-code-review.

**Goal:** 按用户修正，将采购/仓库采购退货清单统一改为履约订单主数据，订单号首列，参考待采购清单样式，关联退货单作为附属信息。
**Architecture:** 保留上游退货资源与独立权限契约；后端按当前授权履约单归并关联退货分摊。一单多退货不重复订单/金额，一退货多订单只展示各自分摊。列表分页/选中导出单位为履约单；可空退货单号不伪造。
**Tech Stack:** Vue3 / NestJS / TypeScript / ExcelJS。
**Spec:** 本轮用户明确更正，覆盖此前独立退货单主视角；仅履约来源进入本清单。
