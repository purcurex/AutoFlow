# 组织部门调整实施记录

**目标：** 管理员清晰可见地删除空部门；销售人员直接归属业务一至四部，取消默认区域组。

**依据：** 用户确认移除区域组、人员直接归属业务部门；组织管理仅系统管理员可访问。

**实现：** 复用现有组织 CRUD 和服务端校验；调整 Vue 页面操作布局。更新新账号种子，已有本地 Demo 通过显式脚本备份并迁移，不在每次读取时重建组织。

- [x] 部门标题旁展示删除操作，确认／取消、请求失败保留节点；含成员或下级部门时说明原因，根组织不可删除。
- [x] 新种子移除欧洲／北美／亚太／大客户四组，15名销售直接归属四部（5／4／5／1人）。保留自定义多级部门能力。
- [x] 本地升级只匹配 HyperZone／营销中心／业务部门下原默认组；保留员工 ID、岗位及账号授权。自定义下级、重复路径或被账号数据权限引用的组跳过，避免扩大权限。
- [x] 前后端测试、构建、实际 Demo 数据与页面检查；更新组织验收文档。

**验收重点：** 普通账号403；管理员业务权限为none仍可管理；删除确认可取消；并发非空状态由服务端拒绝；跨账号引用被拒绝；升级幂等，原员工身份及四部业绩归属不变。

**验证：** 前端241项、后端486项单元测试通过；组织数据库端到端12项通过；lint、前后端build通过。真实本机两个目录各迁移15人、移除4组，迁移前后员工ID、待办数量和回款响应一致。截图 `.runtime/local-demo/organization-departments.png`。
