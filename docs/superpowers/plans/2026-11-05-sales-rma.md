# 销售 RMA 售后清单 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans for inline implementation and superpowers:requesting-code-review for final review.

**Goal:** 销售工作台新增 RMA售后清单，覆盖退款、退货退款、订单拦截、订单取消流程。
**Architecture:** 独立售后快照与独立 allowedRmaCaseIds，复用当前授权履约单关联数据；一单一行，多售后事项合并，金额去重。默认进行中，提供类型和流程状态筛选，沿用部门/仓库、分页、选择及Excel导出。业务办理仍在FOP，不修改主流程队列。
**Tech Stack:** Vue3 / NestJS / TypeScript / ExcelJS。
**Spec:** 用户本轮要求；展示方案按现有工作台订单视角与权限约定，已在进度消息说明。

## Global Constraints
- 当前工作区复用，保留之前未提交变更；不自动提交、推送或改真实FOP配置。
- cancelled和shipmentInterceptStatus不推定售后是否进行中；只读FOP明确流程类型、isOpen及节点文本。
- 拦截/取消/退款可以发生在未支付或已取消订单，不以原待办门槛排除RMA。
- 读取售后快照后复核来源订单当前归属及最新独立授权，导出再次检查；无权事项不搜索、不计数、不展示。
